
## 数据集介绍

| 项目    | 内容                                                              |
| ----- | --------------------------------------------------------------- |
| 目标    | 预测一个人的年收入是否超过 $50,000 美元（>50K）                                  |
| 来源    | 从 1994 年美国人口普查数据提取（Barry Becker, Ronny Kohavi） ([UCI 机器学习库][1]) |
| 样本数量  | 48,842 条记录 ([UCI 机器学习库][1])                                     |
| 特征数   | 14 个属性（特征 + 目标类别） ([UCI 机器学习库][1])                              |
| 特征类型  | 混合（连续、分类） ([UCI 机器学习库][1])                                      |
| 存在缺失值 | 有（部分分类变量中有缺失条目） ([UCI 机器学习库][1])                                |
| 许可证   | CC BY 4.0（可用于研究与改编，只要署名） ([UCI 机器学习库][1])                       |

[1]: https://archive.ics.uci.edu/dataset/2/adult "UCI Machine Learning Repository"
