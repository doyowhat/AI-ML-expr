2.6程序练习

1）统计文本文件中各字母（区分大小写）的出现频率

2）试卷生成器：从网上资源构建任意年级/科目题库，从题库文件中随机挑选出不同的题目生成一份试卷，从对应的答案文件中抽取对应的答案构成标准答案。

3）文件批量处理：程序批量处理一些文件，将根据用户提供的过滤器为它们重命名。比如整理手机图片数据，用户输入的过滤器为myimage##.jpg，那么会生成至少包含3位数的文件名，如myimage001.jpg、myimage145.jpg等，数字次序为处理次序。更进一步，imgDate-#*.jpg表示为img20180516-001.jpg，同时不同类型的文件单独排序编码。
备注：1必做，2/3 任选一个。
